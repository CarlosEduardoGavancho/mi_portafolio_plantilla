Aplicación Móvil de Visualización de Proyectos Regionales

Flutter • Gemini API • Android • Google Maps API • REST/JSON

Descripción del Proyecto

Aplicación móvil Android con mapa interactivo para la geolocalización, difusión y seguimiento de proyectos de desarrollo social en el sur del Perú.

Detalles Clave e Reconocimientos

  • Integración de asistente conversacional automatizado mediante la API de Google Gemini consumiendo endpoints REST/JSON.
  • Desarrollo de panel administrativo para gestión, actualización y publicación dinámica de proyectos.
  • Reconocimiento: Primer Puesto en la Feria de Proyectos de Fin de Semestre de la Facultad de Ingeniería de Sistemas.
