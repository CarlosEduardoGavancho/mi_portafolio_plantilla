API RESTful de Gestión de Propiedades y Alquileres

Node.js • Express • PostgreSQL/Supabase • Prisma ORM • JWT • Postman

Descripción del Proyecto

API de backend orientada a la administración de catálogos inmobiliarios, seguimiento de contratos de alquiler, control de disponibilidad e integración con canales de reserva.

Detalles Clave e Arquitectura

  • Diseño e implementación de arquitectura basada en endpoints RESTful con autenticación y autorización segura mediante JSON Web Tokens (JWT).
  • Optimización de consultas a la base de datos mediante Prisma ORM para filtros avanzados de búsqueda (precio, ubicación, estado de disponibilidad).
  • Pruebas y documentación integral de endpoints para asegurar respuestas HTTP adecuadas (200, 400, 404, 500) y estructuras JSON estandarizadas.
